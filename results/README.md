# Measured evidence

This directory retains only compact outputs generated by commands documented in
the root README. Raw media, caches, downloaded weights, and large benchmark
artifacts are ignored.

The retained evidence comprises the
[SSDLite CPU benchmark](benchmark_ssdlite_cpu.json),
[Faster R-CNN CPU benchmark](benchmark_fasterrcnn_cpu.json), and
[annotated SSDLite demo](annotated_demo.jpg). Their provenance and environment
are documented in the root README.
